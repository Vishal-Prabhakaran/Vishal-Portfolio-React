## ✨ About This Portfolio

Welcome to my personal developer portfolio! This project is built to present my work, technical journey, and creative approach to building delightful web experiences.

The interface combines a clean developer-focused aesthetic with smooth animations, ambient effects, responsive layouts, and an easy-to-navigate structure.

## 🚀 Highlights

- 🎨 Modern dark developer-themed UI
- 📱 Fully responsive design for desktop, tablet, and mobile
- ⚡ Fast development and production builds powered by Vite
- 🧩 Modular React component architecture
- 🎞️ Smooth interactions and animations with Framer Motion
- 🌌 Animated grid background and ambient glow effects
- 📁 Dedicated sections for about, experience, projects, and contact
- 📬 Contact form integration with EmailJS
- ♿ Built with usability and accessible navigation in mind

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) 18 or newer
- npm, included with Node.js

### Installation

```bash
git clone https://github.com/Vishal-Prabhakaran/Vishal-Portfolio-React.git
cd Vishal-Portfolio-React
npm install
```

### Run locally

```bash
npm run dev
```

Open the local URL shown in your terminal to view the portfolio.

### Create a production build

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

## 🎯 Customization Guide

To personalize this portfolio for your own use:

1. Update your introduction and profile details in the relevant files under `components/`.
2. Replace project information, links, and images in the project section.
3. Update social links in the header, sidebars, footer, and contact section.
4. Configure your EmailJS credentials for the contact form.
5. Add your own assets to the `assets/` directory.
6. Run `npm run build` before deployment to verify the production bundle.
